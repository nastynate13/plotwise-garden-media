# Plotwise Garden tutorial media

Public demonstration clips for Plotwise Garden. Published with GitHub Pages independently of Kickstart so website updates do not remove these assets.

The native video players on the landing page provide controls and written steps. Videos do not autoplay. These recordings use isolated sample gardens, not private user data.

Keep versioned paths stable. Add a new version when replacing a clip, then update the tutorial embed in Kickstart. Do not remove old versions until all references have been updated.
